# Handoff 2 — Obsidian formatting guide for the models

Proposal item: "Give OWLA an Obsidian guide that gives the models knowledge of helpful answers and tips for formatting, if the user specifically calls for help, or asks to improve formatting or how something looks. Example: 'professionalising the look of the doc'. See chat for image formatting, since there it gave very useful help."

## Evidence
Session `owla-session-2026-11-23T15-41-01` (opencode, hy4-flash-free). User asked whether pictures can sit side by side. The reply was good: Markdown table with escaped `\|` width aliases (`![[img.png\|400]]`), HTML flex only works with real `<img>` in Reading view, CSS snippet via `cssclasses`, community plugins. That answer came from `obsidian-markdown` luck; we want it deterministic and broader.
