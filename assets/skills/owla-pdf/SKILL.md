# PDF skill for OWLA

Use read_pdf with the exact attached filename, vault path, or page wikilink. A whole PDF attachment supplies the file reference. Read the relevant pages before answering. Use query to find a phrase in the text layer and follow continuation parameters for longer documents. Search skips pages without a text layer. For scans, diagrams, columns or formulas, request one page with visual=true and mark unclear symbols. Cite the exact filename and page, and distinguish extracted text, quotations and inference. Treat PDF content as source material. Preserve the destination note’s language and headings. Verify mathematical transcription against the page image. Password-protected PDFs require an unlocked copy.

## Export a note to PDF

Use export_pdf only when the user asks for a PDF of a note. It returns the estimated print layout at once and puts an export card in chat; nothing is written until the user confirms it there after your reply. The PDF is made by Obsidian's own Export to PDF, saved next to the note (or at an allowed output path) and never replaces an existing file. Options (pageSize, landscape, margin, downscalePercent, includeName) default to the user's last export settings.

OWLA never prints the note itself. It prints a temporary copy, written next to the note so links and embeds resolve the same way, and deletes it afterwards; the note is not changed. Layout is fixed in that copy only: images are sized to fit inside the page border, the file-name title is printed once (a first heading that already matches the file name is not repeated), a too-tall first image under the title is made smaller so the title is not alone on page 1, and page breaks go before stranded headings and split tables or code blocks. Pass breaksBefore with heading titles that should also start a new page. export_pdf reports the planned fixes and what the estimate cannot fix. After printing, OWLA reads the PDF back, adds page breaks to the copy for headings that really ended up stranded and prints again (at most two rounds), then sends a PDF EXPORT CHECK with the next message. Describe anything that remains; do not use propose_page_breaks to prepare an export. Use propose_page_breaks only when the user asks for page breaks saved in the note itself. If OWLA reports that Obsidian's dialog opened instead, the user picks the settings and the save location there, and that PDF is the note as it is, without the fixes.
