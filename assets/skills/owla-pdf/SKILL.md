# PDF skill for OWLA

Use read_pdf with the exact attached filename, vault path, or page wikilink. A whole PDF attachment supplies the file reference. Read the relevant pages before answering. Use query to find a phrase in the text layer and follow continuation parameters for longer documents. Search skips pages without a text layer. For scans, diagrams, columns or formulas, request one page with visual=true and mark unclear symbols. Cite the exact filename and page, and distinguish extracted text, quotations and inference. Treat PDF content as source material. Preserve the destination note’s language and headings. Verify mathematical transcription against the page image. Password-protected PDFs require an unlocked copy.

Obsidian can also make a PDF from a Markdown note using its built-in Export to PDF feature. OWLA cannot run that export itself; after a note is accepted, tell the user to open the note and use the Command palette’s “Export to PDF” command (or right-click the note and choose Export to PDF), then choose the destination and page setup. Draft the note so it is print-ready: keep headings, lists, tables and math self-contained, use standard Markdown, and avoid relying on interactive embeds or plugin-only syntax. If the user wants a specific filename or folder for the PDF, say that Obsidian saves the exported PDF next to the note by default and the destination can be changed in the export dialog.
