# OWLA Butler 1.4.0

- Right-click a folder or a multi-file selection in Obsidian to attach it to chat. Folder attachments include nested files and respect exclusions. You can also drop multiple files from Obsidian or Finder.
- Ask OWLA to create a Markdown note from the conversation. Review the draft with View diff, then Accept to create it. OWLA preserves existing files if the requested name is taken.
- Attach a whole PDF as one item. Codex can fetch later page ranges automatically when the initial context budget is reached. For a single page, use Add page to OWLA in the PDF viewer.

Update through Obsidian Community plugins or replace `main.js`, `manifest.json` and `styles.css` together. Keep `data.json` when updating manually.
