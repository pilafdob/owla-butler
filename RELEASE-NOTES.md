# OWLA Butler 1.5.1

- Dropped PDFs appear as file chips in the draft and sent message. Codex can search the text, read page ranges, or request a scan when it needs one.
- Attaching a folder adds a single chip. Codex can list the folder and search its allowed notes and subfolders. Attached notes and converted documents are read on demand.
- Fixed an oversized Codex protocol error by bounding image payloads and checking size per message.

Update through Obsidian Community plugins or replace `main.js`, `manifest.json` and `styles.css` together. Keep `data.json` when updating manually.
